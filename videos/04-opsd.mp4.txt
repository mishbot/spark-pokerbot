This is OPSD, On-Policy Self-Distillation, how you put a prompt into your bot's weights. At the event, the harness owns the system prompt. Any strategy you want has to live in the weights. OPSD uses one base model twice. The teacher sees the prompt plus your hint. The student sees it without. On each reply, training minimizes the reverse KL between them, token by token, pulling the student toward the teacher. AC2 has three rollout modes: offline replays, stored replies, so nothing is sampled and no inference engine runs; one-step samples, one fresh reply at the prompt boundary; online runs, full rollouts with an environment and a grader. Hackathon orgs can run offline and one-step. Online needs your own agent and grader inside training, so it's not available. It's for behavior that's easy to prompt but hard to reward, like a playing style or a table talk habit. Offline is also cheap, about four GPUs, and no environment, grader, or opponents during training. The catch: offline only reweights what base already writes. For new behavior, use one-step. The starter repo does it in four steps. First, write your own hint. Next, play base on the train deals. Build dataset turns each clean decision into a hinted task.
